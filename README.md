# 电波题库 · A 类业余无线电操作证

纯前端刷题应用，无框架、无 CDN、无构建步骤，打开 `index.html` 即可使用。

## 文件结构

```text
.
├── index.html          # 页面骨架：容器、导航图标 sprite、脚本引用
├── css/
│   └── style.css       # 全部样式与响应式规则
├── js/
│   ├── data.js         # 题库数据（BANK_META + QUESTIONS），替换题库只需改这里
│   └── app.js          # 应用逻辑：刷题 / 背题 / 模考 / 错题本 / 统计
└── README.md
```

## 使用方式

- 直接双击 `index.html` 打开；推荐 Chrome / Edge。
- 也可以用任意静态文件服务器打开，例如：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

- 学习进度、错题本、统计和模考记录保存在当前浏览器的 `localStorage` 中。
  清理浏览器缓存、更换浏览器或使用隐私模式可能导致记录丢失。

## 更新题库

打开 `js/data.js`，修改开头的 `BANK_META` 和 `QUESTIONS` 即可。

字段说明：

| 字段 | 说明 |
| --- | --- |
| `id` | 题号，同一题库内唯一 |
| `category` | 章节 / 分类名称，页面会自动生成筛选与统计 |
| `type` | `single` 单选、`multiple` 多选、`judge` 判断 |
| `question` | 题干 |
| `options` | 选项文本数组；判断题可写 `["对", "错"]` |
| `answer` | 单选 `"A"`；多选 `"AC"`；判断 `"对"` / `"错"` |
| `explanation` | 答案解析；留空时会按标准答案自动生成要点 |

## 关于题库数据

当前数据为 2025 新版 A 类题库 683 题：

- 源数据没有提供章节字段，`category` 按题目内容整理为 8 个章节；
- 源数据没有提供逐题解析，`explanation` 为根据标准答案生成的答案要点，
  可在 `js/data.js` 中替换为更详细的解析。

## 功能

- **刷题模式**：顺序 / 乱序、章节筛选、即时判题、解析、断点续刷、错题自动归档。
- **背题模式**：答案与解析展示 / 隐藏、按章节浏览、键盘操作。
- **模拟考试**：默认 32 道单选 + 8 道多选、40 分钟、30 题合格；题量、时长、抽题范围可调整；倒计时、答题卡、自动交卷、逐题回顾。
- **错题本**：自动收集、单题重做、全部重做、移除已掌握题。
- **学习统计**：已练题数、正确率、章节掌握度、最近 7 天学习量、模考历史。
- **响应式**：桌面、平板、手机自适应。
